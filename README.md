### **MC-online-TCP-forwarding**

##### **简介**

**一种基于服务器 TCP 转发的简易 Minecraft 跨网络联机方案**

缺点：需要一台有公网 IP 的服务器，要自行搭建服务器

**本项目和 Mojang Studios 没有关联**

**部分图片取自游戏内截图，可能与实际有出入**

##### **Cer 证书使用说明**

本项目的 Windows 应用用了自签名的 .msix 包，需要手动导入证书才能使用

###### **证书导入方法：**

[附操作图片](OtherFile/cerUseGuide.png)

1. [打开.cer文件](OtherFile/ShiT0CodeOpenSource.cer)，点击“安装证书”
2. 选择 “本地计算机”然后下一步
3. 选择“将所有的证书都放入下列存储”，点击浏览，选择“受信任的根证书颁发机构”，确定然后下一步完成
**这样就可以安装了**
